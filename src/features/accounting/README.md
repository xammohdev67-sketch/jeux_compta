# Catalogue pédagogique SYSCOHADA

Le fichier `data/accounts.ts` contient un jeu de départ de 100 comptes répartis entre les classes 1 à 8. Il est embarqué dans l’application et consultable hors ligne.

Ce catalogue est une sélection pédagogique, pas le plan comptable officiel exhaustif. Les subdivisions applicables et les libellés doivent être vérifiés avec le référentiel SYSCOHADA révisé et les règles locales avant d’utiliser ces données pour produire des écritures comptables ou des documents réglementaires.
